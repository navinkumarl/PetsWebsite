# Pets Website

A small, static HTML website with informational pages about pets, dogs, cats, fish, and birds. The pets page is the home page. Visitors can navigate between the home page and individual animal pages using the links provided on each page.

## Pages

| Page | Description |
| --- | --- |
| [`pets.html`](pets.html) | Home page about pets, with links to the animal pages |
| [`dogs.html`](dogs.html) | Informational page about dogs |
| [`cats.html`](cats.html) | Informational page about cats |
| [`fishes.html`](fishes.html) | Informational page about fish |
| [`birds.html`](birds.html) | Informational page about birds |

The site uses HTML, embedded CSS on the home page, and JPEG images. It does not require JavaScript, a server, a build step, or package installation.

## Run locally

Open [`pets.html`](pets.html) in a web browser. The animal pages and images use relative paths, so the site files and the [`Images/`](Images/) directory should remain together in the repository structure shown below.
